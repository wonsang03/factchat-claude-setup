# 팩트챗 클로드 자동연결

국립목포대학교 공과대학 **인공지능활용실습** 수업용 설치 도구입니다.
아무것도 깔려 있지 않은 윈도우 PC에서 **bat 파일 하나만 더블클릭**하면,
노드JS · 깃 · 파이썬 · 클로드 코드를 설치하고 학교 팩트챗 게이트웨이에 연결까지 끝냅니다.

명령 프롬프트에 명령어를 한 줄씩 받아 적을 필요가 없습니다.

---

## 준비물

1. 윈도우 10 또는 11
2. 인터넷 연결
3. 팩트챗 API 키 1개

### API 키 발급 방법

1. https://engineering-mokpo-ac.factchat.bot 접속
   *(국립목포대학교 공과대학 전용 주소입니다. 일반 팩트챗 주소가 아닙니다)*
2. **학교 포털 계정**으로 로그인 — 따로 회원가입하지 않습니다
3. 화면 좌측 하단 **[API Gateway]** 클릭
4. **[+ API 키 생성]** → 이름 입력(예: `인공지능활용실습`) → **[생성하기]**
5. 화면에 뜬 키를 **즉시 복사**

> [!WARNING]
> 생성된 키는 **다시 조회할 수 없습니다.** 화면을 벗어나기 전에 반드시 복사하세요.
> 크레딧은 키를 발급한 본인 계정에서 차감되므로 키를 공유하지 마세요.

---

## 사용법

### 1단계 — `.env` 에 키 붙여넣기

`.env` 파일을 메모장으로 열고 아래 줄의 `PUT-YOUR-KEY-HERE` 를 지운 뒤 키를 붙여넣습니다.

```
ANTHROPIC_AUTH_TOKEN=PUT-YOUR-KEY-HERE
```

`=` 앞뒤에 공백을 넣지 말고, 따옴표도 붙이지 마세요. `Ctrl+S` 로 저장합니다.

### 2단계 — `클로드-설정하기.bat` 더블클릭

어느 폴더에 두든 상관없습니다. bat은 자기가 들어 있는 폴더를 기준으로 동작합니다.
단, `클로드-설정하기.bat` · `setup-claude.ps1` · `.env` **세 파일은 같은 폴더에** 있어야 합니다.

### 3단계 — 화면 안내를 따라 Enter

- 설치가 필요하면 `y`
- **"이 앱이 장치를 변경하도록 허용할까요?"** 창이 뜨면 **[예]** (노드JS·깃 설치 시 정상입니다)

키를 안 넣고 2단계부터 해도 됩니다. 스크립트가 메모장을 대신 열어 줍니다.

> 처음 설치하는 PC는 내려받을 것이 많아 5~15분 걸릴 수 있습니다.
> 이미 다 깔린 PC는 1분이면 끝납니다.

## 무엇을 하는가

| 단계 | 내용 |
|---|---|
| 1 | 사전 점검 — 윈도우 버전, CPU 종류, 인터넷, 팩트챗 서버, winget |
| 2 | **노드JS · 깃 · 파이썬** 확인 후 없는 것만 설치 |
| 3 | 기존 클로드 확인 — npm으로 깐 옛 버전이 있으면 정리 |
| 4 | 클로드 코드 설치 (공식 네이티브 인스톨러) |
| 5 | `%USERPROFILE%\.local\bin` 을 사용자 PATH에 등록 |
| 6 | `.env` 에서 키 · 모델 · 접속 주소 읽기 |
| 7 | `%USERPROFILE%\.claude\settings.json` 작성 후 연결 테스트 |

### 설치 방식

| 프로그램 | 1순위 | winget이 없을 때 |
|---|---|---|
| 노드JS | `winget OpenJS.NodeJS.LTS` | nodejs.org에서 최신 LTS msi |
| 깃 | `winget Git.Git` | GitHub 릴리스에서 최신 installer |
| 파이썬 | `winget Python.Python.3.12` | python.org에서 3.12.10 (내 계정 설치) |
| 클로드 코드 | `irm https://claude.ai/install.ps1 \| iex` | — |

- **이미 깔려 있으면 손대지 않고 버전만 표시**합니다. 노드JS가 18 미만일 때만 올릴지 물어봅니다.
- CPU를 판별해 **x64 / ARM64** 설치 파일을 맞춰 받습니다.
- 파이썬은 손글씨 인식 실습의 `pip install -r requirements.txt` 때문에 함께 설치합니다.

### 기존 설정은 지우지 않습니다

`settings.json` 이 이미 있으면 `.bak-날짜` 로 백업한 뒤, `env` 항목의 세 값만 병합합니다.

## 모델 바꾸기

| 모델 | 용도 |
|---|---|
| `claude-haiku-4-5-20251001` | 수업 기본. 크레딧을 가장 적게 씀 |
| `claude-sonnet-5` | 하이쿠로 잘 안 풀리는 무거운 작업 |
| `claude-opus-5` | 설계나 어려운 오류. 크레딧을 가장 많이 씀 |

**잠깐 바꿀 때** — 클로드 입력창에서 바로:

```
/model claude-sonnet-5
```

끝나면 `/model claude-haiku-4-5-20251001` 로 되돌립니다.

**기본값을 바꿀 때** — `.env` 의 `ANTHROPIC_MODEL` 을 고치고 bat을 다시 실행합니다.

> `/model` 로 바꾼 것은 켜 둔 창에서만 유지됩니다. 클로드를 껐다 켜면 `.env` 값으로 돌아갑니다.
> 환경변수가 저장된 설정보다 우선하기 때문이며, 수업 기본값이 하이쿠로 유지되므로 크레딧 관리에 유리합니다.

**크레딧 아끼는 요령** — 평소엔 하이쿠, 안 풀리는 작업만 잠깐 올렸다가 바로 되돌리기.
한 작업이 끝나면 클로드 안에서 `/clear` 로 대화를 비우세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `powershell..은(는) 내부 또는 외부 명령으로 인식되지 않습니다` | PC의 PATH가 망가진 경우. bat이 PowerShell을 절대 경로로 찾도록 되어 있으니, 이 오류가 나면 옛 bat을 쓰는 것입니다. 새로 받아 덮어쓰세요 |
| 압축 안에서 바로 더블클릭 → 파일을 못 찾음 | 압축을 먼저 풀고 그 폴더에서 실행 |
| **7번에서 오류 났다가 재실행하면 통과** | 그 순간 설정 파일이 잠긴 것. 클로드 창을 켜 둔 채 실행했거나, bat을 두 번 눌렀거나, 백신이 막은 경우입니다. 지금은 3번까지 자동 재시도하고, 클로드가 켜져 있으면 알려 주며, 두 번째 설정 창은 스스로 멈춥니다 |
| 연결 테스트 `HTTP 401` | 키가 틀렸거나 해지됨. 팩트챗에서 새로 발급 |
| 연결 테스트 `HTTP 429` | 크레딧 소진 또는 호출 몰림. API Gateway에서 잔액 확인 |
| `'claude' 용어가 인식되지 않습니다` | PATH가 아직 반영 안 됨. PowerShell 창을 **완전히** 닫고(탭만 닫으면 안 됨) 새로 열기 |
| 로그인 방식을 고르는 화면이 나옴 | `settings.json` 이 적용 안 됨. 창을 새로 열고 다시 실행 |
| 파이썬 실행했더니 스토어가 열림 | 윈도우 기본 가짜 python. bat을 다시 실행하면 진짜 파이썬을 설치합니다 |
| 한글이 깨져 보임 | ps1을 직접 실행한 경우. 반드시 bat을 더블클릭 |
| `claude.ai connectors are disabled` | 학교 게이트웨이 접속 시 뜨는 안내 문구. 실습에 지장 없음 |

**오류가 났는데 뭐였는지 모르겠다면** — bat이 있는 폴더에 `설정-기록.txt` 가 자동으로 쌓입니다.
화면에 지나간 내용이 전부 들어 있으니 이 파일을 담당 교수에게 보내면 됩니다.
키는 앞뒤 네 글자만 남기고 가려져 기록되므로 그대로 보내도 안전합니다.

## 파일 구성

```
클로드-설정하기.bat    ← 학생이 더블클릭하는 파일
setup-claude.ps1       ← 실제 설치·설정을 수행 (직접 열 필요 없음)
.env                   ← 키 · 모델 · 접속 주소 (여기에 본인 키를 넣습니다)
README.md              ← 이 문서. 사용 설명서를 겸합니다
```

배포할 때는 위 네 파일을 한 폴더에 담아 압축해 나눠 주면 됩니다.
실행하면 `설정-기록.txt` 가 추가로 생깁니다(실행 기록, 지워도 됩니다).

## 키 관리 주의

> [!CAUTION]
> 이 저장소의 `.env` 에는 키가 들어 있지 않습니다(`PUT-YOUR-KEY-HERE`).
> **본인 키를 넣은 `.env` 를 그대로 커밋·푸시하지 마세요.** 키가 공개되면 크레딧이 남에게 쓰입니다.
> 실수로 올렸다면 팩트챗 API Gateway에서 그 키를 **즉시 해지**하고 새로 발급하세요.

## 환경

- 윈도우 10 / 11, PowerShell 5.1 이상 (윈도우 기본 포함)
- x64 및 ARM64 지원
- **맥은 지원하지 않습니다** — bat과 PowerShell 기반이라 맥에서는 실행되지 않습니다
